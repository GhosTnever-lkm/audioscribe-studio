# Contributing

Contributions are welcome. Keep transcription local by default, keep uploads bounded, and do not add telemetry or a remote transcription provider without updating the privacy documentation.

## Local checks

```powershell
python -m pip install -e ".[dev]"
python -m unittest discover -s tests -v
```

The unit and API tests use generated bytes and fake transcription models; they never download speech model weights. The optional decoder test uses a synthetic WAV and PyAV. Before changing the real audio pipeline, also manually check one short speech sample and a longer file on Windows and Linux, including pause/resume and each export format. Never include a real person's recording in a test fixture.

## Change expectations

- Add regression tests for validation, upload offsets, checkpoints, timestamps, export formatting, and user-visible failures.
- Keep audio reads chunked and avoid `shell=True`.
- Preserve already committed transcript chunks if a later chunk fails.
- Explain disk, memory, and timing impact for new model or file-size options.
- Keep generated model weights, recordings, databases, and local logs out of Git.
